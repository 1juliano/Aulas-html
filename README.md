# 📘 Aulas de HTML

Este repositório contém materiais e exemplos práticos para o aprendizado de **HTML (HyperText Markup Language)**, a linguagem base da web.

---

## 🌐 O que é HTML?

HTML é a linguagem usada para estruturar páginas web. Com ele, definimos títulos, parágrafos, imagens, links, tabelas e muito mais.

---

## 🎯 Objetivo do repositório

Este projeto foi criado para ajudar iniciantes a aprender HTML do zero, com exemplos simples e exercícios práticos.

---

## 📚 Conteúdo das aulas

- Introdução ao HTML
- Estrutura básica de uma página
- Tags principais (`html`, `head`, `body`)
- Títulos e parágrafos
- Links e navegação
- Imagens e mídia
- Listas ordenadas e não ordenadas
- Tabelas
- Formulários
- Boas práticas de organização
